# 📊 End-to-End Telco Customer Churn Analysis & Predictive Modeling

## 📌 Executive Summary
Ringkasan singkat mengenai latar belakang, permasalahan bisnis, dan hasil akhir dari analisis yang kamu lakukan.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Seaborn
* **Tools:** Jupyter Notebook, Excel

## 📈 Key Insights & Results
1. Pelanggan dengan tipe kontrak *month-to-month* menyumbang angka churn tertinggi.
2. Akurasi model Machine Learning mencapai 85% dalam mendeteksi risiko churn.
